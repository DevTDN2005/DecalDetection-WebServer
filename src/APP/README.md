\# APP – Windows Application



\## 1. Overview | Tổng quan



\*\*Tiếng Việt\*\*



Đây là ứng dụng Desktop được phát triển bằng C# trên nền tảng .NET Framework, sử dụng Windows Forms và thiết kế giao diện thông qua Visual Studio.



\*\*English\*\*



This is a Windows Desktop application developed using C# and .NET Framework, with a Windows Forms interface designed in Visual Studio.



\## 2. Development Environment | Môi trường phát triển



\- IDE: Microsoft Visual Studio

\- Programming Language: C#

\- Framework: .NET Framework

\- UI Technology: Windows Forms (WinForms)



\## 3. Project Files | Các file dự án



| File | Description |

|---|---|

| `.cs` | Main application logic and event handling |

| `.Designer.cs` | Automatically generated Windows Forms UI components |



\- `.cs`: Chứa logic xử lý, các hàm và sự kiện của ứng dụng.

\- `.Designer.cs`: Chứa mã nguồn giao diện được Visual Studio tự động sinh ra.



\## 4. Installation \& Execution | Cài đặt và chạy chương trình



1\. Install Microsoft Visual Studio.

2\. Install the Windowns Forms App(.NET Framework).

3\. Open the project or solution in Visual Studio.

4\. Restore required dependencies if necessary.

5\. Build the project.

6\. Run the application using Visual Studio.



\*\*Tiếng Việt\*\*



1\. Cài đặt Microsoft Visual Studio.

2\. Cài đặt đúng Windows Forms App (.NET Framework).

3\. Mở project hoặc solution bằng Visual Studio.

4\. Khôi phục các thư viện cần thiết nếu có.

5\. Build chương trình.

6\. Nhấn Start để chạy ứng dụng.



\## 5. Notes | Lưu ý



\- Keep `.cs` and `.Designer.cs` files together.

\- Avoid manually modifying generated Designer code unless necessary.

\- Ensure the required .NET Framework version is installed.



\- Giữ các file `.cs` và `.Designer.cs` đi cùng nhau.

\- Hạn chế chỉnh sửa trực tiếp file Designer do Visual Studio tự sinh.

\- Đảm bảo đã cài đặt đúng phiên bản .NET Framework.
